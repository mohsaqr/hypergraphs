## Memory networks

A node is a state plus the memory of how it was reached.

- [`sequence-input`](https://pak.dynasite.org/hypergraphs/reference/sequence-input.md)
  : Sequence input shared by the sequence verbs
- [`hon()`](https://pak.dynasite.org/hypergraphs/reference/hon.md) :
  Higher-order network (HON) from sequences

  Embedding of a higher-order network (HONEM)
- [`mogen()`](https://pak.dynasite.org/hypergraphs/reference/mogen.md) :
  Multi-order generative model (MOGen) of sequences
- [`hypa()`](https://pak.dynasite.org/hypergraphs/reference/hypa.md) :
  Hypergeometric anomalies of paths or of co-occurring node pairs

- [`hg_centrality()`](https://pak.dynasite.org/hypergraphs/reference/hg_centrality.md)
  : Centralities of a hypergraph or a memory network
- [`hg_centrality(`*`<net_hon>`*`)`](https://pak.dynasite.org/hypergraphs/reference/hg_centrality.net_hon.md)

- [`hg_communities()`](https://pak.dynasite.org/hypergraphs/reference/hg_communities.md)
  : Communities of a hypergraph or a memory network
- [`hg_communities(`*`<net_hon>`*`)`](https://pak.dynasite.org/hypergraphs/reference/hg_communities.net_hon.md)
  : Memory-network communities with the map equation
- [`hg_bootstrap()`](https://pak.dynasite.org/hypergraphs/reference/hg_bootstrap.md)
  : Bootstrap inference for higher-order network rules
- [`hg_compare()`](https://pak.dynasite.org/hypergraphs/reference/hg_compare.md)
  : Permutation comparison of the rules of two groups
- [`markov_order()`](https://pak.dynasite.org/hypergraphs/reference/markov_order.md)
  : Test the Markov order of sequences
- [`hg_markov_stability()`](https://pak.dynasite.org/hypergraphs/reference/hg_markov_stability.md)
  : Markov stability of the states of a transition network
- [`memory()`](https://pak.dynasite.org/hypergraphs/reference/memory.md)
